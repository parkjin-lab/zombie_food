# FoodTruckPrototype VFX Dummies

These 256x256 transparent PNG files are placeholder VFX sprites for quick prototype feedback.
Import suggestion in Unity: Texture Type = Sprite (2D and UI), Alpha Is Transparency = true.

Files:
- place_success_pop.png: green placement/merge success pop.
- place_fail_flash.png: red invalid placement flash.
- combo_burst.png: yellow combo burst.
- overheat_spike.png: orange heat spike.
- heat_warning_ring.png: amber heat warning marker.
