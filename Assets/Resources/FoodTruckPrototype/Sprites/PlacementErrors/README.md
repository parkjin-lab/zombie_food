# Placement Error Icons

128x128 transparent PNG placeholders for placement fail reasons.
Recommended final style: simple, readable at 18-32 px, no embedded text.

Files:
- placement_fail_no_pending.png: player tried to place without a selected block.
- placement_fail_invalid_anchor.png: anchor/pivot is invalid.
- placement_fail_out_of_bounds.png: footprint leaves the board.
- placement_fail_occupied.png: cell is occupied and cannot merge.
