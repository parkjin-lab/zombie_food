# Food Truck Sprite

Drop the final truck sprite here. The HUD auto-loads the first matching file name:
FoodTruck.png, food_truck.png, Truck.png, truck.png

Recommended source: 512x256 or 384x192 transparent PNG, side-view silhouette facing right. Keep the truck inside the central 90% safe area.
Runtime use: left-side truck marker in each combat lane. When present, the placeholder TRK text is hidden.

Current FoodTruck.png is a prototype placeholder generated by Tools/Create-PrototypeCoreArtPlaceholders.ps1.
Replace it with final art using the same file name when ready.
